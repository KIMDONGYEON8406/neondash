---

## 🔹 프로젝트 개요

- **프로젝트명**: neonDash  
- **장르**: 하이퍼캐주얼 / 장애물 피하기 / 무한 러너  
- **플랫폼**: 모바일(Android)  
- **개발 기간**: 13일  
- **개발 형태**: 1인 개인 프로젝트  

---

## 🔹 주요 기능 및 스크립트

### 캐릭터 이동 
- 캐릭터 자동 전진  
- 좌/우 방향키 입력에 따라 횡이동  
- 이동 제한 범위 지정 (`minX`, `maxX`)

### 무한맵 생성 
- 일정 거리 도달 시 새로운 트랙을 생성  
- `spawnZ` 갱신하며 무한 이어붙이기  
- 반복적으로 동일한 트랙 프리팹을 배치

### 트랙 제거 
- 카메라보다 멀어진 트랙은 자동 제거  
- GC 발생을 직접 컨트롤해 최적화 일부 고려

### 충돌 트리거 처리 
- 도착 지점 또는 충돌 상황 감지  
- 향후 게임 오버, 점수 처리 등 연동 가능

### 카메라 추적 
- `LateUpdate`에서 캐릭터를 부드럽게 따라감  
- 일정 거리 유지하며 카메라 위치 자동 보정

## 🔹 실행 방법

1. Unity 2022.3.21f1 버전에서 프로젝트 열기  
2. `Scenes/StartScene` 실행  
3. `Play` 버튼 클릭 → 캐릭터 자동 이동 시작됨  

---

## 🔹 회고

`무한 트랙 구조를 직접 구현하며, 오브젝트 생성/삭제 타이밍에 따른 퍼포먼스 이슈를 경험했다.
풀링 없이 진행한 구조는 단기적으로는 단순하지만,반복 구간에서 GC 발생으로 인한 프레임 드랍 가능성을 확인했다.
이를 통해 하이퍼캐주얼 게임에서도 퍼포먼스 고려가 필요하며, 이후에는 오브젝트 풀링 도입을 고려할 계획이다.`
